# Quiz Antigravity (v2.0.0)

Версія 2.0 — Повна мобільна адаптація та оптимізація інтерфейсу.

## Основні можливості (v2.0)
- **Мобільний дизайн**: Повноцінне бічне меню ("бургер"), адаптивні форми та квізи для смартфонів.
- **Оптимізований інтерфейс**: Розумні заголовки, які адаптуються під тип контенту та розмір екрану.
- **Виправлення прокрутки**: Повна підтримка скролу на мобільних пристроях для статистики та тестів.
- **Firebase Quiz Storage**: Система завантаження та зберігання тестів у хмарі.
- **Name Uniqueness & Shuffling**: Перевірка унікальності імен та перемішування відповідей.
- **Статистика**: Автоматичне збереження результатів у Firebase Realtime Database та відправка в Google Sheets.
- **Linked Deletion**: Автоматичне видалення результатів та контенту при видаленні тесту.
- **Дизайн**: Сучасний "скляний" Glassmorphism інтерфейс із підтримкою темної теми.

## Технологічний стек

- **Frontend**: React 19, Vite, Lucide React.
- **Backend/DB**: Firebase Realtime Database.
- **Hosting/Deployment**: Підтримує будь-яке статичне оточення або VPS (через `npm run build`).

## Як почати роботу

### Локально
1. Встановіть залежності: `npm install`
2. Запустіть сервер розробки: `npm run dev`

### Деплой
1. Зберіть проект: `npm run build`
2. Скопіюйте вміст папки `dist` на ваш сервер.
