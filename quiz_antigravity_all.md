# Технічний паспорт проекту: Quiz-Antigravity (v3.0 Professional Edition)

Цей документ є повним технічним описом архітектури та функціоналу проекту версії 3.0. Створений для розробників та адміністраторів для розуміння глибокої логіки системи.

---

## 1. Загальний огляд
**Quiz-Antigravity v3.0** — це високотехнологічна навчальна платформа, що поєднує можливості React 19, Firebase та Google Cloud API для створення інтерактивного навчального середовища з автоматизованою звітністю.

---

## 2. Технологічний стек
- **Frontend**: React 19 + Vite.
- **Стилізація**: Vanilla CSS + Glassmorphism v3 (покращена читабельність).
- **База даних**: Firebase Realtime Database.
- **API Інтеграція**: 
  - Google Drive (Media Storage & Gallery).
  - YouTube Data API (Video Playlists).
  - Google Apps Script (External Stats Sync).

---

## 3. Ключові Архітектурні Рішення v3.0

### 3.1. Динамічна конфігурація (Firebase Driven)
Вся структура сайту (Сезони, Сесії, ключі API) зберігається у вузлі `config` бази Firebase. Система динамічно підлаштовується під зміни в БД без необхідності перезбірки коду.

### 3.2. Firebase Quiz Storage (fb: префікс)
На відміну від v2.0, версія 3.0 підтримує зберігання контенту тестів безпосередньо в Firebase. 
- В адмін-панелі можна завантажити `.json` файл.
- Система зберігає його в `quizzes/ID`.
- В конфігурації сесії тест отримує URL `fb:ID`.
- `QuizRunner` розпізнає префікс і завантажує дані через `getQuizContent`.

### 3.3. Розумна Галерея (Drive API)
Компонент `PhotoGallery` реалізує:
- **Прямі запити до API**: Отримання списку файлів за Folder ID.
- **Оптимізація трафіку**: Використання системних мініатюр Google Drive (`sz=w260` для списку, `sz=s3000` для лайтбоксу).
- **Referrer Policy**: `no-referrer` для коректного відображення зображень з Drive.

### 3.4. Статистика та Дедуплікація
При завершенні тесту дані відправляються у два канали:
1. **Firebase `results/`**: Для перегляду в додатку.
2. **Google Sheets**: Через Apps Script (POST).
**Логіка дедуплікації**: У `MainPage.jsx` реалізовано фільтр, що ігнорує записи від того ж користувача з тим же результатом та часом (точність до хвилини) для усунення дублів від випадкових подвійних кліків.

## 4. Структура проекту
```text
/
├── public/                 # Статичні файли (іконки, локальні тести)
├── src/
│   ├── components/
│   │   └── QuizRunner.jsx  # Логіка тестування (v3: підтримка fb: посилань)
│   ├── pages/
│   │   ├── MainPage.jsx    # Головний інтерфейс (v3: Gallery & YouTube модулі)
│   │   └── AdminPage.jsx   # Адмін-панель (v3: завантаження тестів, налаштування API)
│   ├── firebase.js         # Ядро Firebase та Google API Helpers
│   ├── App.jsx             # Роутинг v7
│   └── index.css           # Дизайн-система v3
```

## 5. Формат даних квізу
Версія 3.0 сумісна з попередніми форматами, але рекомендує використання `rationale` для кожного варіанту відповіді для покращення навчання.

---

## 6. Розгортання (Deployment)
1. **Build**: `npm run build`.
2. **VPS**: Рекомендується використовувати Nginx як реверс-проксі для обслуговування `dist/` папки.
3. **Environment**: Всі налаштування (API ключі) вносяться через Адмін-панель після деплою.

**Контроль якості**: Всі компоненти мають вбудовану обробку помилок (Error Boundaries) та стани завантаження (Skeleton loaders/Spinners).
