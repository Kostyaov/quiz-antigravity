# Технічний паспорт проекту: Quiz-Antigravity (Платформа УМШ)

Цей документ є повним технічним описом архітектури та функціоналу проекту. Він створений для того, щоб будь-який розробник або агент зміг зрозуміти структуру, цілі та реалізувати точну копію або розвивати існуючий проект.

---

## 1. Загальний огляд
**Quiz-Antigravity** — це сучасна навчальна платформа для проекту "УМШ", яка забезпечує зручний доступ до навчальних матеріалів (фото, лекції, презентації, програми) та інтерактивні тести з автоматичним збором статистики.

---

## 2. Технологічний стек
- **Frontend**: React 19 + Vite (швидка збірка та HMR).
- **Стилізація**: Vanilla CSS з використанням CSS Variables та ефекту Glassmorphism (скло).
- **Іконки**: Lucide React.
- **Роутинг**: React Router DOM (v7).
- **База даних**: Firebase (за потребою) з повноцінним fallback-механізмом на `localStorage` (що робить додаток автономним).
- **Інтеграція статистики**: Google Sheets через Google Apps Script (POST запроси).

## 4. Принципи роботи

### 4.1. Динамічна конфігурація
Вся структура сайту (Сезони, Сесії, посилання на матеріали) зберігається в об'єкті `config`. Додаток намагається отримати його з Firebase, а якщо Firebase не налаштований — використовує `localStorage`. 
- **Функції:** `getAppConfig()` та `saveAppConfig(config)` у `src/firebase.js`.

### 4.2. Робота з Google Drive (CORS & Links)
Для завантаження JSON-файлів тестів з Google Drive використовується функція `getGoogleDriveDirectLink`, яка перетворює посилання "для перегляду" у посилання "для прямого скачування" (`uc?export=download`).
**Нюанс CORS:** Оскільки Google Drive часто блокує прямі `fetch`-запити з браузера, у `QuizRunner.jsx` реалізована логіка:
1. Спроба прямого `fetch`.
2. Якщо помилка "Failed to fetch" — автоматичне використання CORS-проксі (`allorigins.win`).
3. Рекомендований спосіб: розміщувати JSON у папці `public/` та використовувати локальні шляхи (напр. `/quiz.json`).

### 4.3. Система статистики (Google Sheets)
Результати тестів відправляються у Google Таблицю.
- **Логіка:** `doPost(e)` скрипт у Google Apps Script приймає дані.
- **Особливість:** Скрипт автоматично створює вкладку з назвою сесії (напр. "Сесія 1"), якщо її ще не існує.
- **Ідентифікація:** Перед початком тесту користувач вводить ім'я, яке зберігається у `localStorage`.

## 5. Опис ключових компонентів

### 5.1. MainPage.jsx
- Відображає бокову панель з екшенами (Фото, Лекції, Тести тощо) та верхню панель вибору Сесії.
- **Логіка рендерингу:** Конфігурація має структуру `config.seasons[activeSeason].sessions[activeTab]`. Залежно від обраного ID контенту (лекції/фото), рендериться відповідний Iframe або список квізів.

### 5.2. AdminPage.jsx
- **Доступ:** Захищено паролем (константа `ADMIN_PASSWORD` у `firebase.js`).
- **Можливості:** 
  - Створення нових Сезонів.
  - Редагування посилань на Google Drive Folders, YouTube Playlists для кожної Сесії.
  - Додавання/Видалення тестів (назва + URL).
  - Налаштування `googleScriptUrl` для статистики.

### 5.3. QuizRunner.jsx
- **Механіка:** Завантажує JSON, керує станом поточного запитання, підказками (`hints`) та прогресом.
- **Збереження прогресу:** Кожна відповідь миттєво зберігається у `localStorage`. Якщо користувач оновить сторінку — він продовжить з того ж місця.
- **Завершення:** При натисканні "Завершити" розраховується бал та відправляється POST-запит на `googleScriptUrl`.

## 6. Формат даних квізу (quiz.json)
```json
{
  "meta": { "title": "Назва тесту", "version": "1.0" },
  "quiz": [
    {
      "question": "Текст запитання?",
      "answerOptions": [
        { "text": "Відповідь 1", "isCorrect": true, "rationale": "Чому це правильно" },
        { "text": "Відповідь 2", "isCorrect": false, "rationale": "Чому це ні" }
      ],
      "hint": "Підказка (опціонально)"
    }
  ]
}
```

## 7. Розгортання (Deployment)
1. Створити React проект через Vite.
2. Встановити залежності: `npm install lucide-react react-router-dom`.
3. Скопіювати файли `src/` та `public/`.
4. Для роботи статистики — налаштувати Google Apps Script (код доступний в інструкції проекту).
5. Запустити `npm run dev`.

**Контроль якості:** Код побудований модульно. Якщо ви видалите `AdminPage`, основна частина сайту продовжить працювати на статичній конфігурації.
