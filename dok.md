
# Документація Проекту "УМШ / Сезон 12"

Цей файл містить повну інформацію про архітектуру, принципи роботи та інструкцію з відновлення проекту на іншому комп'ютері.

## 1. Огляд Проекту

Це веб-додаток (Admin Dashboard), розроблений для управління та перегляду навчальних матеріалів (фото, лекції, презентації, тести), розміщених на Google Drive. 

**Ключові можливості:**
- **Навігація по сесіях та сезонах**: Можливість створення та перемикання між різними сезонами та їх сесіями.
- **Категорії матеріалів**: Фото (Google Drive), Лекції (YouTube), Презентації (Google Drive), Тести, Програма (PDF-файл вбудований на сторінці).
- **Інтеграція з Google Drive**: Вбудовування папок Google Drive через `iframe`.
- **Адмін-панель**: Захищений вхід для налаштування кореневої папки Google Drive.
- **Теми оформлення**: Підтримка світлої та темної тем.

## 2. Технологічний Стек

- **Core**: React 19, Vite.
- **Language**: JavaScript (JSX).
- **Styling**: Vanilla CSS (CSS Modules / Global Styles з CSS змінними для тем).
- **Icons**: `lucide-react`.
- **Backend/Persistence**: Firebase Realtime Database (конфігурація) + LocalStorage (фолбек).
- **Routing**: `react-router-dom`.

## 4. Принципи Роботи та Алгоритми

### 4.1. Система Конфігурації (Firebase / LocalStorage)
Файл `src/firebase.js` відповідає за збереження налаштувань.
- **Алгоритм**:
  1. При завантаженні додаток перевіряє `firebaseConfig`. Якщо він містить заглушки ("YOUR_API_KEY"), використовується `localStorage`.
  1. При завантаженні додаток отримує повну конфігурацію (`app_config`) з Firebase або LocalStorage.
  2. Структура даних: `Season (Key) -> Session -> ContentType`.
  3. `MainPage` динамічно завантажує список доступних сезонів та відображає контент обраного.

### 4.2. Інтеграція Google Drive
У `MainPage.jsx`:
- Використовується `iframe` для відображення папок Google Drive (Фото, Презентації).
- Використовується `iframe` YouTube для відображення лекцій (плейлисти або окремі відео).
- Програма відображається через `iframe`.
  - **Автоматична конвертація**: Якщо вказано посилання на перегляд файлу Google Drive (`/view`), воно автоматично замінюється на посилання для попереднього перегляду (`/preview`) для коректного вбудовування.
  - **Підтримка повних посилань**: В адмін-панель можна вставляти повні URL папок Google Drive (наприклад, `https://drive.google.com/drive/folders/...`). Система автоматично витягує ID папки.

### 4.3. Система Firebase та Збереження Даних
Додаток використовує Firebase Realtime Database для наступних цілей:
- **Конфігурація**: Збереження URL-адрес та ID папок Google Drive для кожної сесії.
- **Результати тестів**: Збереження імені користувача, балів та часу проходження.
- **Контент тестів (Quizzes)**: Збереження JSON-даних самих тестів для швидкого завантаження.

### 4.4. Спеціальні можливості тестів
- **Firebase Quiz Storage**: Тести, завантажені через адмін-панель, отримують префікс `fb:`. Система автоматично розпізнає цей контент і завантажує його безпосередньо з БД.
- **Унікальність імен**: Система перевіряє вузол `results` перед початком тесту. Якщо ім'я для даного тесту вже зайняте, користувач побачить попередження.
- **Linked Deletion**: При видаленні тесту в адмін-панелі автоматично очищуються всі пов'язані з ним результати та дані самого тесту в Firebase.

### 4.5. Теми Оформлення
У `index.css` визначені CSS змінні (`--bg-color`, `--text-primary` тощо).
- **Темна тема**: Дефолтні значення в `:root`.
- **Світла тема**: Перевизначені значення в `:root[data-theme="light"]`.
- **Перемикання**: React state `theme` змінює атрибут `data-theme` на елементі `html`.

## 5. Інструкція з Відновлення (Restoration Guide)

Щоб запустити цей проект на новому комп'ютері в середовищі Antigravity або VS Code:

### Крок 1: Підготовка файлів
Копіюйте всі файли проекту збережені в вашому репозиторії або архіві. Переконайтеся, що структура папок збережена.

### Крок 2: Встановлення залежностей
Відкрийте термінал у папці проекту та виконайте команду:
```bash
npm install
```
Це встановить всі бібліотеки, зазначені в `package.json` (`react`, `vite`, `firebase`, `lucide-react` та ін.).

### Крок 3: Запуск сервера розробки
Для початку роботи виконайте:
```bash
npm run dev
```
Сервер запуститься за адресою `http://localhost:5173/` (або інший порт, якщо 5173 зайнятий).



### Крок 4: Налаштування Firebase (Опціонально)
Якщо ви плануєте використовувати справжній Firebase замість LocalStorage:
1. Створіть проект на [Firebase Console](https://console.firebase.google.com/).
2. Оберіть **Realtime Database** та створіть нову базу.
3. Скопіюйте конфігурацію (`apiKey`, `databaseURL` тощо) в `src/firebase.js`.

### Крок 5: Перший запуск
1. Відкрийте додаток у браузері.
2. Перейдіть в "Адмін панель" (кнопка внизу зліва).
3. Введіть пароль: `admin123`.
    - 4.1. Оберіть сезон зі списку або створіть новий, натиснувши кнопку `(+)`.
    - 4.2. Оберіть вкладку потрібної сесії (Сесія 1, 2, 3).
5. Заповніть поля:
    - **Фото/Презентації**: ID папки або повне посилання на папку Google Drive.
    - **Лекції**: URL плейлиста або відео YouTube.
    - **Програма**: Посилання на PDF файл (наприклад, Google Drive link). Додаток автоматично адаптує посилання для вбудовування.
6. Натисніть "Зберегти зміни".

Тепер головна сторінка відображатиме вміст вашої папки.

### Крок 6: Збірка для Продакшену (Optional)
Для створення оптимізованої версії для розгортання на сервері:

```bash
npm run build
```

Ця команда створить папку `dist/` з усіма скомпільованими файлами (HTML, CSS, JS), які готові до завантаження на будь-який веб-хостинг (Vercel, Netlify, Firebase Hosting, FTP).
