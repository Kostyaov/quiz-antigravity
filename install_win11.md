# Інструкція з встановлення залежностей для Windows 11

Цей проект потребує **Node.js** для запуску. Оскільки на вашому комп'ютері його не знайдено, виконайте ці кроки:

## 1. Встановлення Node.js

Найкращий спосіб для Windows — завантажити офіційний інсталятор:

1.  Перейдіть на [nodejs.org](https://nodejs.org/).
2.  Виберіть версію **LTS** (Recommended For Most Users).
3.  Запустіть завантажений `.msi` файл і слідуйте інструкціям.
4.  **Важливо:** Під час встановлення переконайтеся, що опція "Add to PATH" увімкнена (вона увімкнена за замовчуванням).

## 2. Перевірка встановлення

Відкрийте новий термінал (PowerShell або Command Prompt) і введіть:
```powershell
node -v
npm -v
```
Ви повинні побачити номери версій (наприклад, `v22.x.x` та `10.x.x`).

## 3. Встановлення залежностей проекту

Перейдіть до папки проекту в терміналі:
```powershell
cd e:\Programming\quiz-antigravity
```
Виконайте команду для встановлення всіх необхідних пакетів:
```powershell
npm install
```

## 4. Запуск проекту

Після успішного виконання `npm install`, запустіть проект командою:
```powershell
npm run dev
```
Після цього термінал покаже посилання (зазвичай `http://localhost:5173`), за яким додаток буде доступний у браузері.

---
**Порада:** Якщо після встановлення Node.js команди все ще не розпізнаються, спробуйте перезавантажити комп'ютер або перезапустити Antigravity.

## Виправлення помилки "scripts is disabled on this system"

Якщо при спробі запустити `npm` ви отримуєте помилку про те, що виконання скриптів вимкнено (Running scripts is disabled on this system), виконайте наступне:

1.  Відкрийте **PowerShell від імені адміністратора** (правою кнопкою на Пуск -> Terminal (Admin) або PowerShell (Admin)).
2.  Введіть наступну команду і натисніть Enter:
    ```powershell
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
    ```
3.  На запитання дайте відповідь **Y** (Yes).
4.  Перезапустіть термінал і спробуйте знову `npm -v`.
