# Огляд проєкту

Quiz Antigravity — це навчальна платформа для УМШ та пов’язаних подій: звичайних сезонів, літніх/весняних шкіл, з’їздів або інших форматів.

Сайт показує учасникам матеріали навчального циклу:

- програму;
- фото;
- лекції;
- презентації;
- тести;
- статистику результатів для адміністратора.

## Основні ролі

### Учасник

Учасник відкриває сайт, обирає навчальний цикл і сесію, переглядає матеріали та проходить тести. Результати тестів зберігаються в Firebase і, якщо налаштовано, додатково відправляються в Google Sheets.

### Адміністратор

Адміністратор входить у `/admin`, редагує конфігурацію сайту, додає події, сесії, посилання, тести, дивиться статистику й експортує її в CSV.

## Ключові поняття

### Навчальний цикл

У коді й базі історично використовується слово `season`, але фактично це вже ширше поняття: подія або навчальний цикл.

Приклади:

```text
УМШ 12
УМШ Літня школа 2026
УМШ З’їзд 2026
```

Кожний цикл має:

- `title` — назва, наприклад `УМШ Літня школа`;
- `seasonNumber` — номер або рік, може бути порожнім;
- `sortOrder` — порядок у списку;
- `sessions` — три сесії з матеріалами.

### Сесія

Зараз у кожному навчальному циклі є три сесії:

```text
session1 → Сесія 1
session2 → Сесія 2
session3 → Сесія 3
```

Кожна сесія може мати:

- посилання на програму;
- Google Drive папку з фото;
- YouTube playlist або відео з лекціями;
- Google Drive папку з презентаціями;
- список тестів.

### Тест

Тест може бути:

- локальним JSON-файлом із `public/tests/`;
- зовнішнім JSON за URL;
- JSON, завантаженим через адмінку прямо у Firebase.

Рекомендований сучасний спосіб — завантажувати JSON через адмінку. Тоді тест отримує посилання виду:

```text
fb:QUIZ_ID
```

Це прибирає більшість проблем із CORS і зовнішніми посиланнями.

### Статистика

Результати тестів зберігаються у Firebase `results/`. Якщо в адмінці задано Google Apps Script URL, результат також відправляється в Google Sheets.

В адмінському режимі на сайті доступний розділ `Статистика` з експортом CSV.

## Поточна логіка середовищ

### Локально

Команда:

```bash
npm run dev
```

використовує `.env.development`:

```text
VITE_DATA_MODE=local
```

У цьому режимі дані зберігаються тільки в `localStorage` браузера. Бойова Firebase не змінюється.

### Production

Команда:

```bash
npm run build
```

використовує `.env.production`:

```text
VITE_DATA_MODE=firebase
```

Production-сайт читає і записує дані у Firebase відповідно до правил безпеки.
