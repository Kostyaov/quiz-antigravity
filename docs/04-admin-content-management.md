# Адмінка і керування контентом

Адмінка доступна за адресою:

```text
/admin
```

Локально:

```text
http://localhost:5173/admin
```

На сайті:

```text
https://uames.pp.ua/admin
```

## Вхід

### Локально

```text
admin@local.test / admin123
```

Це працює тільки в `npm run dev`.

### Production

У production використовується Firebase Authentication. Користувач має:

1. існувати у Firebase Authentication;
2. мати UID у Realtime Database:

```json
{
  "admins": {
    "FIREBASE_AUTH_UID": true
  }
}
```

## Важливе правило збереження

Адмінка редагує форму локально в браузері. Зміни потрапляють у Firebase тільки після натискання:

```text
Зберегти зміни
```

Якщо є незбережені зміни, адмінка показує попередження перед виходом.

## Навчальні цикли

Навчальний цикл — це подія або програма: сезон УМШ, літня школа, з’їзд тощо.

Приклади коректних назв:

```text
УМШ 12
УМШ Літня школа 2026
УМШ З’їзд 2026
```

У формі є поля:

- назва програми/події;
- номер або рік;
- порядок сортування;
- зробити поточним циклом.

Підпис формується без слова `Сезон`: назва + номер/рік.

## Сесії

У кожному циклі зараз є три сесії:

- Сесія 1;
- Сесія 2;
- Сесія 3.

Для кожної сесії можна заповнити:

- фото;
- лекції;
- презентації;
- програму;
- тести.

## Програма

Поле `Програма` приймає URL або PDF link.

Якщо це Google Drive file link виду:

```text
https://drive.google.com/file/d/FILE_ID/view?usp=sharing
```

сайт автоматично перетворює `/view` на `/preview` для вбудовування.

## Фото

Для фото можна вставляти:

- Google Drive Folder ID;
- або повне посилання на папку Google Drive.

Якщо задано Google API key, сайт використовує власну галерею `PhotoGallery` з мініатюрами. Якщо ключа немає або щось не спрацювало, можливий fallback через Google Drive embed.

Папка має бути доступною для перегляду за посиланням.

## Лекції

Поле `Лекції` приймає:

- YouTube playlist URL;
- або посилання на окреме YouTube відео.

Якщо є playlist і API key, сайт показує власну галерею відео. Інакше використовує стандартний YouTube embed.

## Презентації

Презентації працюють як Google Drive embedded folder. Можна вставити Folder ID або посилання на папку.

## Тести

Рекомендований шлях:

1. Підготувати JSON-файл тесту.
2. У адмінці ввести назву тесту.
3. Вибрати JSON-файл.
4. Натиснути `Додати`.
5. Натиснути `Зберегти зміни`.

Після завантаження тест зберігається у Firebase `quizzes/` і в конфігурації отримує URL:

```text
fb:QUIZ_ID
```

Це найнадійніший формат.

## Формат JSON-тесту

Мінімальна структура:

```json
{
  "quiz": [
    {
      "question": "Питання",
      "answerOptions": [
        {
          "text": "Варіант",
          "isCorrect": true,
          "rationale": "Пояснення"
        },
        {
          "text": "Інший варіант",
          "isCorrect": false,
          "rationale": "Пояснення"
        }
      ],
      "hint": "Підказка"
    }
  ]
}
```

Рекомендовано додавати `rationale` для кожного варіанту — тоді тест краще працює як навчальний інструмент.

## Видалення тестів

Коли тест прибирається із сесії, остаточне видалення контенту тесту і результатів виконується тільки після `Зберегти зміни`.

Це зроблено навмисно, щоб випадковий клік не знищував дані миттєво.

## Експорт та імпорт конфігурації

В адмінці є:

- `Експорт JSON` — завантажити поточну конфігурацію файлом;
- `Імпорт JSON` — підставити конфігурацію з файлу;
- `Відновити` — повернути останній локальний бекап форми.

Імпорт не зберігає зміни на сайт автоматично. Після імпорту треба перевірити дані й натиснути `Зберегти зміни`.

## Локальні бекапи конфігурації

Перед збереженням адмінка зберігає попередню конфігурацію в `localStorage`.

Зберігається до 10 останніх бекапів.

Це не замінює серверний бекап або експорт Firebase, але дуже допомагає при випадкових змінах у формі.

## Статистика

Розділ `Статистика` доступний тільки адміністратору.

Там можна:

- подивитися кількість респондентів;
- середній бал;
- максимальний і мінімальний бал;
- розгорнути результати за тестами;
- скачати CSV.

CSV експортується з налаштуваннями для Excel:

- UTF-8 BOM;
- `sep=;`;
- розділювач `;`.

Файл має відкриватися в Excel без ручного імпорту.
